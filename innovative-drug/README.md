# innovative-drug/ — 创新药概念成分股快照工作区

单次抓取的离线产物：**创新药概念成分股清单（135 只）+ 行情/价格区间/最近买点数据**，与 `src/` 应用代码完全解耦。数据基准日 2026-10-08（A 股盘中快照，非收盘数据）。

与 `screening/`（全池均线筛选，按基准日累积批次）相互独立：本工作区为**概念板块成分股一次性快照**，无定时/累积机制。

## 目录结构

```
innovative-drug/
├── README.md                          # 本说明
├── 创新药概念股.html                    # 交互视图（数据内嵌，双击即开、离线可用）
└── data/
    └── 2026-10-08.innovative-drug.json  # 135 只全量字段 + 口径元信息（唯一权威数据源）
```

- HTML 为可再生的只读视图：135 只数据全部内嵌，支持表头点击排序（升/降切换、「#」恢复默认）与代码/名称搜索，无需起服务；
- JSON 是唯一数据源：HTML 与其它衍生物一律从它生成。

## 成分口径

- 基础池：创新药概念板块股票池快照（2026-10-08 10:43 盘中，175 只）；
- 筛选：剔除北交所（4 只）与 ST/\*ST（8 只，\*ST康乐 与北交所重叠，去重后剔除 11 只）→ 再剔除科创板 sh688（44 只）→ 剩 120 只；
- 补充：手工指定 15 只相邻概念股（CRO/原料药等，如药明康德、昭衍新药、新和成），`inClsPool: false` 标记，视图名称带 `*`；
- 最终 **135 只**（沪市 47 / 深市 88），全量剔除与补充清单见 JSON `meta.filter.removedList` 与 `meta.extra.codes`。

## 字段口径（详见 JSON `meta.fields`）

| 字段                                    | 口径                                                                                                                                                                                                          |
| --------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 现价 / todayHigh                        | 腾讯实时报价（qt.gtimg.cn），盘中抓取                                                                                                                                                                         |
| 半年最高 / 一年最高（含日期）           | 前复权日 K（fqkline qfq）区间最高价与当日盘中最高取大；窗口起点 2026-04-08 / 2025-10-08，含当日                                                                                                               |
| lastBuyPointDate                        | 最近一次 B 点形态成立日：三日强涨 + 第 3 日收盘 ≥ MA30 + 动能保护，与 `docs/SIGNAL_RULES.md` 第一节及 `screening/screen.mjs` `isBuyPattern` 同口径，不含持仓状态约束；扫描 2024-10 起前复权日 K，截至最近收盘 |
| 涨跌幅 / 领涨次数 / 流通市值 / 资金流向 | 2026-10-08 盘中快照；补充股的领涨次数与资金流向未提供（null → 显示「—」）                                                                                                                                     |

## 已知口径差异

- 前复权口径下历史高价已按分红除权调整，与不复权行情软件显示可能不同；
- fqkline 盘中不含当日日线（多为最后 bar 止于前一交易日），故当日数据一律以实时报价合并；
- 补充股的快照类字段（涨跌幅/流通市值）为补充时点实时值，与池内股的 10:43 快照存在时点差。
