# KLineChart A 股行情预览（Preview）

基于 [KLineChart](https://github.com/klinecharts/KLineChart) v10 与腾讯行情接口构建的 A 股 K 线预览应用。覆盖沪（sh）、深（sz）、北（bj）三市场，支持个股、指数与科创板标的；无需后端服务，浏览器直连行情数据源，开箱即用。

在线体验：[preview.klinecharts.com](https://preview.klinecharts.com)

## 功能特性

### 行情与数据

- **三市场覆盖**：沪市、深市、北交所，输入 6 位代码自动按前缀推断市场（`60/68/900` → sh，`43/83/87/88/92` → bj，`00/20/30` → sz），股票名称实时补全
- **常用标的一键切换**：默认提供上证指数、深证成指、创业板指、沪深 300、科创 50、中证 500
- **周期齐全**：分时、1/5/15/30 分钟、1/4 小时、日、周、月；主栏直接展示日/周/月，其余收进「周期」菜单。腾讯不直接提供的周期（如 4 小时）由 60 分钟线本地聚合而成
- **历史加载**：向左滚动按需加载更早数据，每次 500 根；日/周/月线为前复权
- **实时更新**：A 股无免费浏览器 WebSocket 行情，以 3 秒轮询腾讯接口刷新最新一根 K 线；分时模式下跨交易日自动整体重载切换到新交易日
- **时区**：图表固定 `Asia/Shanghai` 时区

### 分时图

- 面积走势线（白线）+ 均价线（黄线）+ 昨收基准虚线
- **双 Y 轴**：右侧价格轴，左侧百分比涨跌幅轴（价格与昨收百分比实时互换显示）
- **昨收居中**：Y 轴区间以昨收为中心对称化，基准虚线始终位于面板中线
- **全天一屏**：按 A 股一个交易日 242 根分钟线（09:30–11:30、13:00–15:00 各 121 根）自动计算 bar 宽度，未交易时段右侧留白，时间锚点位置全天恒定
- **X 轴交易时段锚点**：`09:30 / 10:30 / 11:30/13:00（午休合并） / 14:00 / 15:00`，窄屏自动精简为首、午休、尾三个
- **均价线口径按标的区分**：
  - 个股：官方「累计成交额 ÷ 累计成交量」，科创板（688/689，每手 200 股）自动换算；接口缺成交额（北交所）时退回 `close × volume` 近似
  - 指数：成交额与成交量之比约为全市场平均股价，与点位不在同一量级，改用按量加权的指数点位均值，保证黄线贴合白线
- **切换体验**：分时形态（指标、坐标轴、样式）延迟到数据就绪后与数据注入同帧应用，加载期间旧图原样保留，无白屏、无中间形态闪屏

### 指标

- **主图指标**：MA、EMA、SMA、BOLL、SAR、BBI
- **副图指标**：VOL、MACD、KDJ、RSI、BIAS、CCI、WR、DMI、OBV、PSY、DMA、EMV、ROC、TRIX、VR、MTM，以及自定义「换手率」「振幅」指标
- **覆盖内置 MA**：tooltip 图例并入 K 线 tooltip，数值颜色与图上均线一致，实时跟随参数修改
- **覆盖内置 VOL**：量柱红绿改按昨收判定，与 K 线红绿同步（内置为按今开判定，假阴/假阳线时两者不一致），符合 A 股软件习惯
- **指标参数设置弹窗**：中英文参数标签、最小值钳制、整数/小数参数区分（如 BOLL 标准差支持 0.01 步进）；工具栏入口当前处于隐藏状态，见「已知限制」

### 基本面信息表格

- **行情 + 基本面混排**：一张表格同时展示 K 线行情（时间、今价、今开、最高、最低、均价、涨跌、振幅）与基本面（换手率、成交量、总市值、流通市值、市盈 TTM/动/静、市净率）
- **十字光标联动回溯**：悬停历史 K 线时，振幅、换手率由 K 线精确重算；估值与市值类指标按收盘价比例回溯（近似值）；未悬停时显示接口最新值
- **数据来源**：腾讯实时行情接口，按标的缓存，切换标的强制刷新；接口返回 GBK 编码，浏览器端 `TextDecoder` 解码
- **自适应布局**：PC 端 8 列 2 行，移动端 4 列 4 行

### 图表交互与外观

- **A 股配色**：红涨绿跌，按昨收判定（`compareRule: 'previous_close'`），K 线、最新价标记、指标量柱全局统一
- **右键切换鼠标选择**：右键图表关闭十字光标，tooltip 与信息表格固定显示最新一根；再次右键恢复跟随鼠标
- **明暗主题**：一键切换，CSS 变量与 klinecharts 主题联动，切换后自动重应用 A 股配色、分时面积图样式与十字光标状态
- **绘图工具**：直线、线段、射线、水平线、垂直线、价格线、价格通道线、平行直线、斐波那契回调线、画笔、注释；支持一键清除
- **中英文界面**：URL 追加 `#en-US` 切换英文
- **移动端适配**：工具栏按行分区换行、加大触控目标
- **样式隔离**：所有选择器以 `#app` 为前缀平铺书写，可安全嵌入宿主页面；深色主题由根节点 `dark` 类驱动

## 技术栈

| 依赖 | 用途 |
| --- | --- |
| [klinecharts](https://github.com/klinecharts/KLineChart) v10 | 图表引擎（唯一运行时依赖） |

## 快速开始

环境要求：Node.js ≥ 18

```bash
npm install
npm run dev
# 打开 http://localhost:5173
```

## 项目结构

```
├── index.html          # 入口 HTML（meta、#app 挂载点）
├── public/
│   ├── CNAME           # GitHub Pages 自定义域名 preview.klinecharts.com
│   └── logo.svg        # 站点图标与图表水印
├── src/
│   ├── main.ts         # 应用入口：挂载 #app 并启动
│   ├── app.ts          # 核心实现（详见下文）
│   ├── index.css       # 全部样式：主题变量、工具栏、弹窗、移动端适配
│   └── app.test.ts     # 单元测试
├── tsconfig.json
└── vitest.config.ts
```

`src/app.ts` 是唯一的核心模块（`setupApp` 入口），包含：

- **自定义注册**：`registerYAxis` 百分比涨跌幅轴；`registerIndicator` 分时均价（TIME）、VOL、MA 覆盖版、换手率、振幅
- **数据层**：腾讯接口请求与解析（K 线、分时、实时/基本面、代码搜索）、周期映射与本地聚合、市场推断、`DataLoader`（`getBars` / `subscribeBar` 轮询 / `unsubscribeBar`）
- **分时状态机**：激活/退出、形态同帧切换、全天一屏校准、跨交易日重载、在途切换保护
- **UI**：工具栏（标的搜索、周期、指标开关、绘图、主题）、指标参数弹窗、信息表格渲染与十字光标联动

## 数据源

全部为腾讯公开行情接口，自带 CORS 允许头，浏览器可直接跨域访问：

| 用途 | 接口 |
| --- | --- |
| 分钟 K 线（m1/m5/m15/m30/m60） | `ifzq.gtimg.cn/appstock/app/kline/mkline` |
| 日/周/月 K 线（前复权） | `ifzq.gtimg.cn/appstock/app/fqkline/get` |
| 分时（当日分钟价格、累计量额、昨收） | `web.ifzq.gtimg.cn/appstock/app/day/query` |
| 实时行情与基本面（GBK 编码） | `qt.gtimg.cn` |

npm test

覆盖范围：

- **指标参数设置弹窗**：打开/关闭、参数渲染、标签与步进、钳制与取整、提交 `overrideIndicator`
- **数据源纯函数**：时间解析（三种格式）、腾讯 K 线解析与坏行过滤、按毫秒桶聚合、市场推断、周期键
- **分时图**：激活仅切周期、退出恢复蜡烛图、数据就绪后形态同帧应用与全天一屏校准、失败兜底、在途切走放弃注入、A 股配色
- **鼠标 K 线选择**：右键开关、crosshair 钉住/恢复、关闭期间重钉
- **分时纯函数**：分时点解析（量额差分、科创板换手、北交所缺额、非交易时段过滤）、均价计算（个股/科创板/缺额/指数四种口径）、昨收选取、对称区间

## 已知限制

- **指标参数设置弹窗入口被隐藏**：弹窗实现与测试完备，但工具栏「指标设置」按钮容器带 `display: none`（`src/app.ts`），界面上暂无打开入口
- 标的搜索仅支持 6 位数字代码：腾讯 smartbox 接口无 CORS 头，无法在浏览器端按名称搜索，名称通过实时行情接口补全
- 副图「换手率」指标为相对最大成交量的近似展示（浏览器端无流通股本数据）；信息表格中的换手率为接口真实值，两者口径不同
- 行情依赖腾讯公开接口，接口变更或限流时数据可能中断；分时/基本面在请求失败时显示空网格与 `--` 占位
