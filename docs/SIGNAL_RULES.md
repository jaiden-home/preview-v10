# 极速模拟 · 买卖点信号规则

> 引擎：`src/lib/trading/signal.ts` 的 `dailySignals(bars, startDate)` —— 逐日**因果**求值（只用当日及之前数据，无未来函数），起始日前历史只作上下文不出点。
> 展示：`ChartTerminal.setSimSignals` 注入，`SIM_SIGNAL` 指标在日 K 柱**低点下方（B）/ 高点上方（S）**绘制圆形徽记（B = 红 `--up`，S = 品牌蓝 `--tb-active`）。
> 性质：**纯客户端本地展示，对单一用户生效，不入服务端账务**。UI 展示规范见 `docs/UI_SPEC.md` §3.13。

---

## 一、B 点（买入开仓）

**前置状态：空仓**（从未开仓，或上一对 B/S 已完成离场）。

当日为「连续 3 日强涨」的第 3 日，且以下条件**全部满足**：

### 1. 三日强涨形态（`BUY_RUN_DAYS = 3`）

窗口内每一天（对**上一交易日**比较，非当日开盘）：

| #   | 条件                                                                       |
| --- | -------------------------------------------------------------------------- |
| 1-1 | 当日最高价 ≥ 前一交易日最高价 × 0.999（含 0.1% 容差，平高/针尖误差不断链） |
| 1-2 | 当日收盘价 > 前一交易日收盘价（收盘过收盘）                                |

- 任一天不满足 → 链断，重新累计
- 「低开小阳线」（收盘 > 开盘但 < 前日收盘）**不算**上涨

### 2. 均线门槛

**第 3 日收盘价 ≥ MA30**（30 日收盘简单均线；窗口不足 30 根不判定）。

### 3. 动能保护（双条件公式）

记 **R1 / R2 / R3** = 窗口第 1 / 2 / 3 日各自的**单日涨幅**（当日收盘 ÷ 前一交易日收盘 − 1）。
**任一成立即拦**（即 B 要求同时满足两条下限）：

| 拦截条件           | 常量                        | 含义                                                 |
| ------------------ | --------------------------- | ---------------------------------------------------- |
| R1 × 50% > R2 + R3 | `BUY_TAIL_REPAIR_MIN = 0.5` | 后两日合计接不回首日涨幅的一半——首日大涨后无有效修复 |
| R2 × 15% > R3      | `BUY_FADE_RATIO = 0.15`     | 第 3 日涨速衰竭至第 2 日的 15% 以下                  |

- **与成交量无关**；涨速不降（R3 ≥ R2）天然满足；≥ 含等于

### 4. 时序约束

- **空仓**才开仓：S 未出现前，后续强势日不重复标 B
- **模拟起始日（含）之后**才开仓：起始日前强涨不开仓
- 无未来函数，当日收盘确定即判定

### 5. 开仓副作用

- **止损基准 = B 前一交易日的最低价**（供 S1 使用）
- B 日成交量 ≥ 前日 3 倍 → 同日记入 **S3 基准**
- B 日最高价创近 120 日新高 → 同日记入 **S4 基准**
- 开仓日（B 日）**不判 S**

## 二、S 点（卖出离场）

**前置状态：持仓**（B 日之后逐日收盘判定）。**五条先触发者离场，一枚 B 只对一枚 S。**

### 决策点：趋势乘骑分支（每日动态判定，只影响 S1/S2）

进入条件：MA30 已**连续超过 15 个交易日**（`SELL_TREND_STREAK_DAYS`，严格大于）高于 MA60，不看乖离比值；MA60 窗口不足不进入分支。

| 分支       | 价格离场条件                                                                     |
| ---------- | -------------------------------------------------------------------------------- |
| **乘骑段** | **收盘价 < MA60** → 当日标 S（S1/S2 整体被替换——骑趋势、防 MA30 震出与过早止损） |
| **常规段** | 走原 S1 / S2                                                                     |

### S1 止损（常规段）

收盘价 **< B 前一交易日的最低价** → 当日标 S。

### S2 趋势离场（常规段）

**连续 2 个交易日收盘价 < MA30** → 第 2 日标 S（MA30 窗口不足不判定）。

### S3 放量破位（两分支皆生效）

- **记录**：持仓期某日成交量 **≥ 前一交易日的 3 倍**（`SELL_SPIKE_RATIO = 3`，含恰好）→ 记**当日收盘价**为基准；再放量取最近一枚
- **触发**：其后**首次连续 2 个交易日收盘 < 基准** → 第 2 日标 S
- **清零**：期间某日收盘 ≥ 基准（收复）→ 断开重数

### S4 高位破位（两分支皆生效）

- **记录**：持仓期某日最高价**创近 120 个交易日（约半年）新高**（`SELL_HIGH_LOOKBACK_BARS`，严格高于回看内全部高点）→ 记**当日收盘价**为基准；再创新高取最近一枚
- **触发**：其后**首次连续 3 个交易日收盘 < 基准** → 第 3 日标 S
- 单日收涨但未收复基准**不断链**；收复即清零

### S5 连跌破位（两分支皆生效）

- **确认**：持仓期出现**连续 3 个交易日收盘 < 各自上一交易日收盘**（三连阴；任一日收涨即断链清零）→ 记**第 3 日的最低价**为基准；再次三连阴重记
- **触发**：其后**首次连续 2 个交易日收盘 < 该最低价** → 第 2 日标 S（收复即断开）

## 三、框架语义（全局）

1. **B 必须先于 S**：空仓期间任何 S 条件满足都不标 S
2. **B/S 成对交替**：S 出现前不再标 B；S 离场后空仓，待下一枚 B 重新武装
3. **基准随仓位生命周期**：S3/S4/S5 基准**只在持仓期记录**（B 日及之后），**S 离场即全部复位**，不带入下一对 B/S；空仓期与起始日前的放量/新高/连跌不记录
4. **先触发者离场**：同日多条 S 命中只标一枚；B/S 同日冲突 B 优先
5. **乘骑分支只替换 S1/S2**：S3/S4/S5 在任何分支下照常兜底
6. **起始日前**：历史只作上下文（MA30/MA60/三日比较/半年回看），不出点、不开仓、不记基准
7. **因果性**：全部判定只用当日及之前数据；虚拟日推进到当天收盘即出点
8. **本地性**：纯客户端计算，对单一用户生效，不入服务端账务与成交链路

## 四、常量总表

| 常量                      | 值   | 用途                     |
| ------------------------- | ---- | ------------------------ |
| `BUY_RUN_DAYS`            | 3    | 三日强涨窗口             |
| `BUY_TAIL_REPAIR_MIN`     | 0.5  | 动能保护：R2+R3 ≥ 50%×R1 |
| `BUY_FADE_RATIO`          | 0.15 | 动能保护：R3 ≥ 15%×R2    |
| `SELL_TREND_MA_DAYS`      | 60   | 乘骑分支锚定均线 MA60    |
| `SELL_TREND_STREAK_DAYS`  | 15   | 乘骑分支多头持续天数     |
| `SELL_SPIKE_RATIO`        | 3    | S3 放量倍数              |
| `SELL_HIGH_LOOKBACK_BARS` | 120  | S4 半年回看              |
